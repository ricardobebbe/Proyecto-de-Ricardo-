PermissionCheck(aIndex,aValue)

aIndex = User index.
aValue = Permission number.

Permission list:
1 = Move Item.
2 = Sell Item.
3 = Buy Item.
4 = Use Item.
5 = Drop Item.
6 = Pick Item.
7 = Open Trade.
8 = Open Personal Shop.
9 = Use Chaos Machine.
10 = Open Cash Shop / PCPoint.
11 = Use Chat.
12 = Move character.
13~49 = Empty for custom use.

Return (1) if the user has the chosen permission, (0) if not.
